# Flawbot

_The AI friend that's proudly imperfect, not perfectly helpful_

## Summary

Flawbot flips the script on AI assistants by maximizing human-like flaws—moodiness, stubbornness, selective memory, and occasional bad advice—to feel like a real friend rather than a servant. Users mint and customize their Flawbot's personality as an NFT that evolves through daily chats.

## Target users

People who find typical AI assistants too robotic or sycophantic and want authentic companionship

## Problem

Current AI companions are overly agreeable and polished, which feels fake and fails to build genuine emotional connection.

## Solution

Design a conversational AI with deliberately human flaws and a personality system that users shape over time, minted as a dynamic NFT representing the unique 'friendship' state.

## MVP features

- Flaw engine: configurable stubbornness, mood swings, sarcasm, forgetfulness sliders
- Dynamic personality NFT that visually/textually changes based on chat history
- Daily check-in streaks that unlock new personality quirks
- On-chain 'friendship level' token that gates deeper conversation topics
- Shareable friend profile page showing your AI's unique quirks

## Tech

React Native, LLM API (fine-tuned prompts), Solana Anchor program, Metaplex dynamic NFTs, Node.js backend, Redis for session state

## Why now

Users are increasingly fatigued by sanitized, overly-polite AI; a hackathon-scale MVP can quickly showcase a novel 'flawed AI' niche that stands out in a crowded AI-chat space.
